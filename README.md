# SkyElite Estudos

Landing page institucional da SkyElite Estudos, desenvolvida com React, TypeScript e Vinext.

## Requisitos

- Node.js `>=22.13.0`

## Desenvolvimento local

Instale as dependências:

```bash
npm run install:ci
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

## Build e pré-visualização

Gere a versão de produção:

```bash
npm run build
```

Depois, inicie a pré-visualização local:

```bash
npm run start
```

## Estrutura principal

- `app/`: páginas e rotas da landing page
- `components/`: componentes reutilizáveis
- `public/`: imagens e arquivos públicos
- `scripts/`: ferramentas de desenvolvimento
